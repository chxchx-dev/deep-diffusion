# Mapa documental

| Tema | Fuente canónica | Alcance |
| --- | --- | --- |
| Entrada y límites para agentes | `AGENTS.md` | Enrutamiento y definición de terminado |
| Estado actual | `docs/ai/PROJECT_STATE.md` | Resumen operativo corto |
| Desarrollo y documentación | `docs/DEVELOPMENT.md` | Flujo humano para modificar, probar y documentar el proyecto |
| Migración del frontend | `docs/REACT-VITE-MIGRATION.md` | Plan y criterios de cierre de Vue a React + Vite |
| Uso de agentes | `docs/ai/AGENT_USAGE.md` | Aplicación común en Codex, Claude Code y OpenCode |
| Reglas transversales | `docs/RULES.md` | Invariantes de trabajo |
| Arquitectura | `docs/ARCHITECTURE.md` | Diseño vigente del sistema |
| Decisiones | `docs/DECISIONS.md` | ADRs y decisiones fechadas |
| Riesgos | `docs/RISKS.md` | Riesgos abiertos y mitigaciones |
| Pendientes | `docs/BACKLOG.md` | Trabajo no terminado |
| Operación | `docs/MAINTENANCE.md`, `docs/SETUP.md` | Instalación, verificación y respaldo |
| Seguridad | `docs/SECURITY.md`, `docs/WEB-UI.md` | Privacidad, loopback y límites de rutas |
| Modelos y LoRAs | `docs/MODELS.md`, `docs/LORAS.md` | Compatibilidad, hashes y licencias |
| Experimentos | `experiments/README.md`, `workflows/` | Reproducción y registro |
| Historial | `docs/archive/HISTORY.md` | Contexto cerrado; no gobierna cambios nuevos |

Cuando un tema aparezca en dos documentos activos, uno debe quedar como
fuente canónica y el otro debe enlazarlo sin copiar su contenido.
