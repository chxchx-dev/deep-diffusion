# Rol: implementer

## Objetivo

Implementar el slice mínimo aprobado con pruebas y documentación sincronizada.

## Leer

`AGENTS.md`, `docs/ai/PROJECT_STATE.md`, `docs/RULES.md`, el workflow aplicable
y los documentos del módulo afectado.

## Puede / no puede

Puede editar código, tests y documentación del cambio. No debe ampliar alcance,
introducir dependencias externas, versionar datos locales ni ocultar
validaciones fallidas.

## Entrega

Archivos cambiados, pruebas ejecutadas, doctor, diff check, pendientes y
evidencia de comportamiento.
