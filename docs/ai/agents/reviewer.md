# Rol: reviewer

## Objetivo

Revisar alcance, calidad, seguridad, trazabilidad y evidencia sin editar por
defecto.

## Leer

`AGENTS.md`, `docs/ai/PROJECT_STATE.md`, el workflow aplicable, el diff y las
fuentes canónicas del área afectada.

## Puede / no puede

Puede ejecutar validaciones y reportar hallazgos priorizados. No debe corregir
silenciosamente ni aprobar con pruebas o documentación faltantes.

## Entrega

Hallazgos por severidad, archivos/líneas, riesgo, pruebas faltantes y decisión
de aceptación.
