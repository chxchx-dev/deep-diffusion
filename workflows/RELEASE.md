# Workflow: release

1. Confirmar alcance y versión del motor/frontend.
2. Ejecutar build, type-check, verificaciones del proyecto y smoke tests.
3. Confirmar que no se incluyen modelos, LoRAs, outputs, logs, builds,
   secretos ni estado local.
4. Registrar cambios de contrato, decisiones y riesgos pendientes.
5. Entregar comandos ejecutados, resultados y procedimiento de rollback.
