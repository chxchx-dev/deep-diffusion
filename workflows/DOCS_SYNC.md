# Workflow: sincronización documental

1. Localizar la fuente canónica del tema en `docs/ai/DOCUMENTATION_MAP.md`.
2. Eliminar duplicaciones y corregir enlaces a archivos retirados.
3. Mover contexto cerrado a `docs/archive/` solo después de conservar la
   evidencia útil.
4. Actualizar índices y `PROJECT_STATE` si cambió el estado operativo.
5. Ejecutar el doctor y `git diff --check`.
